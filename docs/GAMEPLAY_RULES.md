# 玩法参数与触屏操作

2026-11-20。`src/game/types.ts`、`balance.ts`、`engine.ts`、`ai.ts`、`controls.ts` 和 `touch-hud.ts` 为唯一事实来源。本轮保留开局 1500 金 / 600 木 / 0 油、基础采集 20 / 秒、货仓 100 和人口 80，调整兵种协同、科技节奏与操作。

## 维修

- `[REPAIR]` 工人维修己方已完工建筑；未完工建筑仍执行续建。显式 `repair` 命令、工人右键建筑和触屏点击建筑共用权威校验。建筑选中后点击维修，自动指派附近未在施工的工人；工人选中后点击维修或按 J，进入目标选择模式。
- `[RATE]` 第一位作业工人 24 HP / 秒，第二位乘 0.6，第三位乘 0.4，其余不增加速度；单建筑最大 48 HP / 秒。工人必须到达有效作业位置，移动途中不加血、不花资源。
- `[COST]` 修复费用为建筑原始金 / 木 / 油费用 × 恢复 HP / 最大 HP × 0.5；逐帧按实际修复量扣除，资源不足暂停，有零头时只恢复可支付的生命，绝不负库存。比如指挥中心修复 100 HP，花费 50 金 / 25 木 / 10 油。
- `[LIFECYCLE]` 满血停止，目标死亡不复活，玩家改令取消；维修完成后恢复原采集节点并保留货物。命令、维修活动和恢复节点随 v2 存档保存，联机只由服务器修改 HP 与银行。工人使用施工姿态，建筑显示治疗闪光与施工声，选中工人或建筑均可查看真实维修进度。

## AI

- `[INFORMATION]` 决策读取己方状态、当前可见敌军、已探索地形与公开出生区锚点。侦察前不读取隐藏敌方兵种、科技、银行或动态基地状态；生产命令仍执行与玩家相同的规则。
- `[ECONOMY]` 按金 / 木 / 油配额及库存缺口分配工人，逃离可见敌军火力，研究 / 建设预留预算，生产队列按建筑限制。重建关键设施，续建失去施工工人的建筑，安全远矿区逐步增设交付点。
- `[DEFENSE]` 来袭敌军接近基地、交付点或工人时立即防守，无需等首攻计时；受损建筑优先维修，缺电补电站。正常情况留守基础步兵，出击单位成组推进。
- `[TACTICS]` 对可见炮塔生产火炮、步兵集群生产狙击手、空军优先对空单位；补充坦克、医疗、机甲和空军以维持混编。撤回残血单位、兵力严重劣势时回撤，医疗跟随集群，火炮 / 狙击手避让近身威胁，集中攻击高威胁目标。
- `[DIFFICULTY]` 休闲 / 标准 / 挑战目标工人数 10 / 12 / 14，首攻最早 150 / 100 / 65 秒，进攻阈值 11 / 9 / 7，撤退生命阈值 20% / 28% / 35%。标准和挑战启用集火、拉距与劣势回撤；没有额外资源、伤害或生产速度。

## 操作与界面

- `[TOUCH]` 单击点选，双击选当前视野内同类，三击选全图己方移动单位（含工人）。连续点击间隔 ≤330ms、位移 ≤28px。长按 420ms 后进入框选，立即拖动则平移；第二根手指、取消事件、失焦均取消框选，捏合抬指不下令。
- `[HUD]` ≤800px 或主指针为触屏时使用独立 48px 顶栏和约 150px 透明底部指令；只有按钮、摘要和小地图捕获触摸，中间空白仍可操作战场。详细信息、兵种筛选与调度按需展开。底部安全区、横屏、双语均适配，生产 / 队列 / 小地图 DOM 与桌面共享；切换桌面和触屏布局时收起调度。移动端同时最多显示两条通知，单行高度 30px，多选摘要和详情使用触屏提示。
- `[GROUPS]` 触屏「保存」后点击 1–3 记录编队；点击编号召回，再次点击定位。空闲入口逐一定位空闲工人；「筛选」保留选中兵种或移出工人。三击仍选择包含工人的全部移动单位。
- `[VIEWPORT]` 禁止页面快捷键、Ctrl / Cmd 滚轮、双击与手势缩放，输入框至少 16px 以避免 iOS 聚焦放大。战场相机的捏合 / 滚轮缩放保留。浏览器菜单缩放、系统放大和浏览器强制辅助设置无法由网页禁用。

## 前哨试点

双湖边境和环形山谷使用现有前哨资源点。标准 AI 在约 35 秒起侦察己方前哨，具体时机受策略影响。有战车工厂和足够工人后，AI 会在主油点剩余约 1,200 或库存不足时准备扩张，经济策略可以更早投入。两名步兵护送前哨施工，完工精炼厂附近的前哨金矿会获得采集车。进攻优先考虑已发现的敌方前线补给建筑。

小地图显示已探索的前哨和己方在产油井的剩余开采时间。主金矿剩余 800、主油点约剩 35 秒、油井断供或补给线受袭时，己方收到可点击定位的提示。战局统计和 JSON 导出记录首批前哨资源入账、前哨 360 世界像素内首次造成或受到伤害、首辆坦克出场及补给事件。
