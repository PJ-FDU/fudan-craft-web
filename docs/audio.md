# 游戏声音

`src/game/faction-sounds.ts` 定义阵营音效和循环，`src/game/faction-voice.ts` 定义中英文台词，`src/game/audio.ts` 将战场事件映射到这些素材。音效位于 `public/assets/audio/factions-v1/`，四族 Qwen 录音位于其 `voice-qwen3-v1/` 子目录。

## 阵营音色

| 阵营 | 战场和设施 | 交战与通讯 |
| --- | --- | --- |
| 工业联邦 | 发电机低鸣、金属敲击、重型设备运转 | 枪炮爆发、弹着冲击、带电台滤波的军用通讯 |
| 生群共生体 | 巢体呼吸、脉冲、孵化组织蠕动 | 爪击和喷吐、带短混响的巢群回应 |
| 星能议会 | 晶体共鸣、相位波动、充能脉冲 | 能量放电、晶体撞击、带泛音的同步通讯 |
| 远行者同盟 | 风噪、车载供电、装配站机械运转 | 轻型机炮、金属跳弹、车队电台 |

四族素材合计 668 个 MP3，包括 269 个短音效、91 个循环和 154 条台词的双语录音。每族有独立的战场底噪和间歇声。41 组阵营建筑声覆盖待机、生产、选中、放置、完工和摧毁。23 个按阵营区分的攻击单位或防御设施各有开火和命中声，23 项主动技能各有释放声。36 个阵营单位以及收拢后的装配站均有独立语音。每族另有开场、完工、受袭和战果等九类指挥播报。

## 玩家操作

首次点击或按键后，浏览器允许播放背景音乐。主菜单右上角「声音」控制整体静音。「游戏设置」和战场「战局控制」提供总音量、音乐、战斗与界面、环境和部队语音五路音量。在「试听阵营」中选择种族，然后点击「试听部队通讯」即可听到该阵营的开局单位。主菜单「EN / 中文」和两处设置的语言选项同时切换界面、录音和字幕。偏好保存在浏览器，默认开启声音，总音量为 70%。

主菜单播放远征主题。镜头附近出现可见交火时，战场在 1.4 秒内混入战斗配乐，最后一次交火后保持 7 秒再退回探索。地图风声和附近水声与所属阵营的环境声混合，平静时插入各阵营的间歇声。建筑根据所属阵营、距离和作业状态播放。战局暂停时保留低音量配乐，后台标签页挂起音频上下文。

单位会回应选中和移动。作战单位另有攻击指令台词，支援单位有技能指令台词，工兵有采集、维修和施工回应。普通回应至少相隔 5 秒，忙时丢弃。语音单路播放，警报优先，播报时音乐降到当前设置的 40%。字幕跟随实际录音。

## 验证规则

- **AUDIO-VISIBILITY**：战斗声只消费 `Engine.view(side).events`。隐藏敌方事件不能绕过视野过滤。
- **AUDIO-FIRE**：开火用 `fire`，命中用 `impact`，主动技能用成功释放后生成的 `cast`。攻击和技能音色取发起单位所属阵营。自动治疗响应 `heal`。
- **AUDIO-ONCE**：同一事件 ID 在连续快照间只播放一次；新战役、读档、网络首帧和暂停恢复建立新基线。超过 0.8 秒的旧事件不补播。
- **AUDIO-BOUNDS**：战斗距离衰减半径 1150 世界像素，立体声声像以 700 像素归一化，最多 24 路短音效；总线压缩器限制交火峰值。
- **AUDIO-VOICE**：普通选中与指令回应共享 5 秒节流；已有语音或加载任务时直接丢弃普通回应。重要播报最多三条待播，3.5 秒后过期；基地警报 14 秒、单位损失 12 秒。静音、切后台、离开战场或切换语言立即取消当前及加载中的旧台词。
- **AUDIO-BUILDINGS**：环境声来自 `Engine.view` 中的可见建筑，在 650 世界像素内按距离衰减，最多三个来源。选中和正在作业的建筑提高优先级。生产取实际 `produce` 状态，施工与维修由正在工作的工兵、获得节点覆盖的星能工程或装配站的状态决定。缺电时停止耗电建筑的运行声。已离开的来源在 0.2 秒内淡出。
- **AUDIO-LANGUAGE**：中文路径保持兼容，英文语音使用 `en-` 文件名前缀；非语音素材两种模式共用。解码缓存以完整路径区分语言，不能把旧中文缓冲当作英文录音。
- **AUDIO-LOAD**：按需解码音频，同一文件共用加载任务；失败后间隔 15 秒才重试，不让网络故障产生每帧请求。

## 重新生成四族素材

在 Apple Silicon 的 Python 3.12 环境中安装 `mlx-audio==0.6.7` 和 `scipy`，并安装 Node 项目依赖和带 `libmp3lame` 的 FFmpeg。配音使用锁定版本的 [Qwen3-TTS VoiceDesign 1.7B MLX 4-bit](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-4bit/tree/5c390979e4b93af5f2932f90742ca99c7dd04687)。

```sh
npm run audio:generate -- --factions
python scripts/generate-faction-voices.py --language both --resume
```

音效使用固定随机种子合成。配音脚本用中英文角色提示生成声线，并叠加阵营滤波。`--model` 可指定已下载的权重目录，`--resume` 根据输入签名和文件校验值复用已验证录音。游戏按需读取随站发布的 MP3。

## Qwen3-TTS 中英文配音

兼容旧存档的九种机动单位与指挥播报由 [Qwen3-TTS VoiceDesign 的 MLX 4-bit 转换](https://huggingface.co/mlx-community/Qwen3-TTS-12Hz-1.7B-VoiceDesign-4bit/tree/5c390979e4b93af5f2932f90742ca99c7dd04687) 本地合成。每种语言有 59 条录音，字幕来自语音目录。

在 Apple Silicon 的 Python 环境中安装 `mlx-audio==0.6.7`。安装 Node 项目依赖和带 `libmp3lame` 的 FFmpeg 后，在项目根目录执行：

```sh
python scripts/generate-qwen-voices.py --language zh
python scripts/generate-qwen-voices.py --language en
```

首次运行会下载约 2.31 GB 的模型。已有本地权重时可传入 `--model` 目录，使用 `--output` 可把 MP3 写入试听目录。`--new-only` 可保留台词未修改的现有 Qwen 素材。运行游戏时直接加载随站发布的音频。

## 重新生成共享配乐和旧音效

使用带 `libmp3lame` 的 FFmpeg 重建音效、建筑声和配乐：

```sh
npm run audio:generate
```

脚本通过固定随机种子合成原创 PCM 音效、建筑声与配乐，并检查发布目录中的中英文配音齐全。可用 `FFMPEG_PATH` 指定工具路径。临时 WAV 会自动清理。

素材共 176 个 MP3，包括 37 个音效、21 个循环和 118 条配音（两种语言各 59 条）。三段配乐均为 80 BPM、48 秒；风、水及旧工业循环为 12 秒，建筑循环为 8 秒，采样率 44.1 kHz。音乐及音效 128 kbps，录音为单声道 96 kbps。旧 `machinery` 素材保留在生成清单，运行时由各建筑音轨替代。

`npm test` 验证两种语言的素材覆盖、设置校验、静音时取消加载中的台词、可取消前摇、真实弹着时机、视野过滤、去重、读档与状态播报；`npm run build` 验证发布包。开发模式打开 `/tests/audio-render.html` 可解码全部音频素材并检查混音与静音输出。正式读档及真实点击已验证 2D / 3D 的工厂选中音、生产循环、施工声、木材厂锯切声、资源选中音和英文字幕。独立状态检查覆盖施工停工、缺电、距离、三个来源上限及切换语言时取消旧录音。
