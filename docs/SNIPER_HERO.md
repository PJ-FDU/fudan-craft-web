# 工业联邦 · 幽影狙击手精修

幽影狙击手使用独立 Blender 高低模工程、2048² PBR 和专用双手握持求解。图鉴与对局加载同一份 `sniper.glb`。

[实际游戏前后对照](../artifacts/sniper-hero/revision-comparison.png) · [头颈姿态修正对照](../artifacts/sniper-hero/neck-pose-comparison.png) · [握枪、右倾与稳定头颈](../artifacts/sniper-hero/handpose-inspection.png) · [握枪侧面](../artifacts/sniper-hero/grip-side-detail.png) · [披风动作](../artifacts/sniper-hero/cape-motion.gif) · [电影光追瞄准](../artifacts/sniper-hero/cinematic-aim.png) · [可编辑工程](../artifacts/sniper-hero/ghost-sniper.blend)

角色重新制作了圆润的袖口和裤腿、堆积褶皱、开口兜帽、护目镜、面罩、耳机、围巾、分片披风、背包、背带、弹药袋、护膝、鞋底与手套指节。腰胸按椭圆截面渐变，胸甲使用弧形收边薄壳，腰带环绕腰部，背包上下收窄。轻型护甲、布料、橡胶和金属分别使用独立材质定义，迷彩和织物微法线由安装坐标控制。

步枪采用精密栓动步枪的外形逻辑：骨架枪托与托腮板、枪机柄、侧面内凹枪机窗口、保险杆、独立弹匣、开放扳机护圈、浮置长枪管、通风护木、导轨、镜座、分段物镜与目镜、调节旋钮和收拢两脚架。枪口内壁、制退器侧孔及护木空隙均有实际几何；镜片置于遮光罩内部。左手在前，掌心朝上承托护木；右手在后，指节围住握把、食指进入护圈。枪托抵向右肩，上身略向角色自身右侧倾。枪械由独立 `rifle` 骨骼驱动。

## 源码与物理锚点

- `[SNIPER-SOURCE]` 造型、材质与烘焙参数以 `scripts/build-sniper-hero.py` 为准。骨骼由 `scripts/export-blender-source.ts` 从游戏源码导出；生成器不另造游戏关节。
- `[SNIPER-RIG]` 保留前 15 个关节的名称、顺序和父子关系，追加 `rifle` 和两侧各四段披风，共 24 骨。`humanoid-models.ts` 为狙击手定义肩部横向偏移 ±5.4、上臂 7.6、前臂 6.5；其余人形兵种保持原定义。整枪刚性绑定 `rifle`，披风使用相邻骨骼混合权重。
- `[SNIPER-GRIP]` `unit-rig.ts` 的 `sniperGrip` 按两段手臂实际长度求解。右腕追踪后方握把的枪械原点，左腕追踪前方护木的枪械局部 `(-0.6, -0.55, 6.2)`，沿枪轴相隔 6.2，左掌相对枪械旋转 X = −π/2。肘部优先向下收拢。枪械在角色根坐标系 Y = −0.30rad、Z = 0，枪托靠向右上胸与肩窝，左肩到前护木保持在实际臂长范围。低姿携枪时枪口下倾约 0.28rad，移动时持枪收近身体；瞄准平举，后坐时枪口轻抬。
- `[SNIPER-STANCE]` 站立上身向自身右侧倾斜约 4°，瞄准权重 0.8 时约 6.8°；源码 Z = `−(0.07 + aim × 0.06)`，步态叠加幅度 0.035rad，倒地时侧倾渐退。上身朝右轻转 `aim × 0.12rad`，前倾为 `weight × 0.055 + aim × 0.075 − recoil × 0.055`。双手接触点仍在躯干坐标系求解。
- `[SNIPER-NECK]` 头部和枪械使用 `inverse(hips × torso)` 抵消父骨骼侧倾，角色根坐标系的头部滚转为 0。贴腮仅从绑定位置 `(0, 14, 1)` 移到 `(0.5, 13.35, 1.05)`，最大位移约 0.822；头部沿镜轴轻转，保持稳定，不跟随枪口后坐抬头。禁止自由横移头部去匹配枪位。
- `[SNIPER-EYE]` 瞄准权重达到 0.65 后，先固定头颈，再从右眼锚点 `(1.2, 1, 2.89)` 推算枪位，使枪械目镜后的 `(0, 3.7, -3.06)` 对齐眼位，眼距约 0.95。先算枪位再求双臂，避免手部接触正确却把头颈拉离身体。
- `[SNIPER-CAPE]` `LCape0…3` / `RCape0…3` 每段长度 7，根部位于肩后 `(±2.9, 10.4, -4.9)`。每个顶点最多混合相邻两段。摆动按时间、移动权重和转向计算，逐段延迟，左右相位错开；关闭动画时回到绑定形态，无累计帧漂移。Blender 可编辑骨架使用相同混合权重。
- `[SNIPER-SCALE]` 枪械沿前后轴长约 28.66，镜身长 8.8，枪管轴相对枪械原点高度为 1.65；握把安装向前偏移 2。坐标是游戏世界单位，不代表实际毫米。
- `[SNIPER-UV]` 独占 2048 × 2048 图块。低模智能展开后以凹形 UV 岛打包，岛距 0.0015、padding 8px。颜色、切线法线和 ORM 三张纹理打包进可编辑工程。
- `[SNIPER-BAKE]` 246 个安装组分别沿 X 分离 100 单位，高低模投射 extrusion 0.20、最大距离 0.65；组装后烘焙 AO。超过 5% 有效像素缺损会终止。小范围缺损由低模材质自投射修复，保留原始缺损与中性法线回退数。
- `[SNIPER-PUBLISH]` 发布先校验生成器 SHA-256、骨骼与投射覆盖率，再移除通用工业包中的旧狙击手，保留其它网格的压缩块。清单增加独立 `sniper` 材质页和生成来源；通用工业 `.blend` 中的旧狙击手也移除，现役工程是 `ghost-sniper.blend`。

## 编辑与重建

打开 [ghost-sniper.blend](../artifacts/sniper-hero/ghost-sniper.blend)。`01 · GAME LOW` 包含两个游戏合批网格和可编辑骨架；`02 · HIGH` 保存默认隐藏的高模。材质纹理已打包。重建会覆盖程序生成工程，手工编辑前应另存。

```sh
npm run assets:sniper
npm run assets:sniper -- --device CPU
npm run check:blender -- artifacts/sniper-hero/verification.json
npm run build
# 只检查形体，不发布
npm run assets:sniper -- --preview-only
```

正式全库或分族 `assets:sculpt` 完成后，会恢复工程采集车与狙击手的专用资产。临时源数据和本轮执行日志放在 `/tmp/fudancraft-sniper-*`。

本角色使用程序制作的形体和 PBR，并非扫描材质或逐笔雕刻。玻璃沿用不透明反射，披风采用骨骼风摆而非物理布料模拟；尚未加入专用 LOD。近景质量与大量同屏的性能需要分别验收。
