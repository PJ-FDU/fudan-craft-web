# 快捷键设置与单位 / 建筑说明

入口：主菜单「游戏设置 → 自定义快捷键」与「战术档案」。战场选中面板提供「生产条件与技能」，调度按钮的悬停 / 焦点提示显示生产条件。

## 战场显示与下拉组件

- 「显示血条（单位与建筑）」默认开启，覆盖满血单位；「显示建筑名称」默认关闭。两项独立保存于操作偏好，旧配置缺失建筑名称字段时使用关闭状态。
- 关闭建筑名称仍显示施工进度与生产进度；关闭血条不影响选择圈、任务和选中面板中的生命数值。
- 所有下拉框使用 `src/game/dropdown.ts` 的 `GameSelect`，包括快捷键、档案、房间自定义地图和地图编辑器。禁止添加原生 `<select>`。
- 选项值通过 `dropdownMarkup` 编码，动态列表用 `setOptions` 更新。选择后派发冒泡的 `change`；程序设置 `value` 不派发事件。
- 弹出列表使用顶层 popover，并根据可视视口上下翻转与左右限位。触屏选项点击不会因触发按钮提前失焦而被吞掉；外部点击、焦点离开、Esc、关闭对话框或组件移除会关闭列表。

## 触屏布局

- 编队工具与七个快捷指令各占完整一行；宽度不超过 360px 时快捷指令按四列分成两行，底部按钮的点击区域至少为 44px。
- `TouchHUD` 用 `ResizeObserver` 更新底栏实际高度，镜头工具与指令提示依此定位。展开筛选、切换横竖屏或改变安全区后，不得与底栏重叠。
- 调度和详情面板受动态视口与安全区约束，可触摸滚动；调度的关闭按钮固定在面板顶部。视口高度不超过 500px 时，面板占据顶部栏与底部快捷指令之间的空间。
- 打开调度或详情面板时隐藏镜头工具；未解锁项目只降低模型图标饱和度和亮度，名称与费用保持可读。
- 浏览器回归覆盖 390×660、390×844、320×568、844×390 及桌面恢复；检查触摸滚动、关闭按钮、筛选下拉和浮动工具的边界。
- 移动端规则以 `(max-width:800px), (pointer:coarse)` 为准，不能只按窄屏判断：横屏手机也需要 44px 点击区域。主菜单使用内容流，短屏允许滚动；进入战役设置时重置标题页滚动位置。
- 通用弹窗的标题与关闭按钮固定在顶部，新页面重置滚动位置；弹窗和编辑器按 `visualViewport.height / offsetTop` 限位，防止输入时被键盘遮挡。设置、通知、快捷键、档案折叠项和图鉴按钮均遵循同一触屏尺寸。
- 技能面板与底栏一起测量，不能按固定 `bottom` 压在编队、摘要或操作按钮上；恢复桌面时，技能、小地图和生产面板都必须回到原位置。
- 编辑器的触屏工具箱默认收起，选中笔刷后自动收起；「移图」模式拖动不会修改地图，绘制模式保留撤销。缩放按钮可触摸操作，退出按钮保持可见；第二根手指不能创建新笔画或结束第一根手指的笔画。
- 扩展回归覆盖主菜单、战役设置、选图、设置 / 快捷键、档案、联机大厅、模型 / 动画图鉴、编辑器及战场技能 / 施工 / 任务 / 统计面板；分别检查中文、英文、短视口输入与桌面恢复。
- 英文步骤导航不能覆盖 44px 最小按钮宽度；战场详情折叠入口同样保持 44px 高。设置完成按钮位于全部选项之后。
- 错误提示挂载到当前弹窗中，避免原生 `dialog` 顶层遮挡；关闭弹窗后恢复到游戏容器。联机房间号校验失败必须在弹窗内可见。

## 快捷键

- 按选择 / 战局、单位指令、训练槽位、资源建筑分组；可按名称、单位或按键搜索。
- 点击按键框捕获键盘输入，或使用旁边的按键列表。Esc 取消捕获；不接受修饰键、输入法组合事件、重复按键、数字编队和固定界面按键。
- 冲突显示占用操作的名称，只在点击「交换」后修改两项。单项恢复默认遵循同一冲突流程；也可恢复全部默认。
- 保存仍使用 `fudancraft-operations-v1`，旧的有效配置可直接读取。配置维持一键一操作。
- 种族与生产建筑只影响预览，不改变对局设置。实际训练槽位取决于对局种族和选中的已完成生产建筑；提示标签与键盘派遣共用 `productionBindings`。
- HUD、帮助和暂停提示显示当前配置。切换语言保留快捷键面板的展开状态、搜索和预览。

## 信息来源与验证规则

源码是规则的唯一事实来源：

| 内容 | 源码 |
| --- | --- |
| 名称、基础属性、费用、训练 / 建造时间 | `src/game/types.ts` 的 `STATS` |
| 种族阵容、生产建筑、前置科技、人口与覆盖 | `src/game/races.ts` |
| 技能效果及研究前置 | `src/game/abilities.ts` 的 `ABILITIES` |
| 用途文案及英文 | `src/game/unit-descriptions.ts`、`src/game/locale-dictionary.ts` |
| 共用档案字段与展示 | `src/game/unit-information.ts` |
| 搜索与筛选 | `src/game/field-manual.ts` |
| 战场生命、升级属性、任务进度与暂停原因 | `src/game/selection-info.ts` 与当前 `ViewState` |

`producerFor`、`prerequisitesFor`、`populationWeight`、`supplyProvided` 同时供规则和展示使用。调整生产或科技规则时应修改这些来源，禁止在界面重新维护一份种族解锁表。

档案按种族显示单位和建筑（包括指挥中心），支持技能支援筛选，并可搜索技能、用途和条件。显示的是基础值；战场选中面板显示当前快照值。虫群采集车来自孵化巢，工业干扰车需要支援模块，星能生产设施需要能量节点覆盖。技能列表分别标注初始可用或研究名称、等级与研究建筑。

选中信息区折叠保留在同一个单位的实时刷新过程中。队列暂停原因区分缺电、失去覆盖、迁移与换装；非工业种族不会因为未使用的电力属性显示「缺电暂停」。

验证命令：`npm test`、`npm run build`、`npm run build:pages`、`node scripts/check-pages-build.mjs`。浏览器需覆盖冲突交换 / 取消、单项重置、保留键、刷新持久化、种族与建筑预览、档案筛选 / 技能搜索，以及桌面和 390px 窄屏。
