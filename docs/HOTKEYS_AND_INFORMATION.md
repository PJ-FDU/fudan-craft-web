# 快捷键设置与单位 / 建筑说明

入口：主菜单「游戏设置 → 自定义快捷键」与「战术档案」。战场选中面板提供「生产条件与技能」，调度按钮的悬停 / 焦点提示显示生产条件。

## 快捷键

- 按选择 / 战局、单位指令、训练槽位、资源建筑分组；可按名称、单位或按键搜索。
- 点击按键框捕获键盘输入，或使用旁边的按键列表。Esc 取消捕获；不接受修饰键、输入法组合事件、重复按键、数字编队和固定界面按键。
- 冲突显示占用操作的名称，只在点击「交换」后修改两项。单项恢复默认遵循同一冲突流程；也可恢复全部默认。
- 保存仍使用 `fudancraft-operations-v1`，旧的有效配置可直接读取。配置维持一键一操作。
- 种族与生产建筑只影响预览，不改变对局设置。实际训练槽位取决于对局种族和选中的已完成生产建筑；提示标签与键盘派遣共用 `productionBindings`。
- HUD、帮助和暂停提示显示当前配置。切换语言保留快捷键面板的展开状态、搜索和预览。

## 信息来源与验证规则

源码是规则的唯一事实来源：

| 内容 | 源码 |
| --- | --- |
| 名称、基础属性、费用、训练 / 建造时间 | `src/game/types.ts` 的 `STATS` |
| 种族阵容、生产建筑、前置科技、人口与覆盖 | `src/game/races.ts` |
| 技能效果及研究前置 | `src/game/abilities.ts` 的 `ABILITIES` |
| 用途文案及英文 | `src/game/unit-descriptions.ts`、`src/game/locale-dictionary.ts` |
| 共用档案字段与展示 | `src/game/unit-information.ts` |
| 搜索与筛选 | `src/game/field-manual.ts` |
| 战场生命、升级属性、任务进度与暂停原因 | `src/game/selection-info.ts` 与当前 `ViewState` |

`producerFor`、`prerequisitesFor`、`populationWeight`、`supplyProvided` 同时供规则和展示使用。调整生产或科技规则时应修改这些来源，禁止在界面重新维护一份种族解锁表。

档案按种族显示单位和建筑（包括指挥中心），支持技能支援筛选，并可搜索技能、用途和条件。显示的是基础值；战场选中面板显示当前快照值。虫群采集车来自孵化巢，工业干扰车需要支援模块，星能生产设施需要能量节点覆盖。技能列表分别标注初始可用或研究名称、等级与研究建筑。

选中信息区折叠保留在同一个单位的实时刷新过程中。队列暂停原因区分缺电、失去覆盖、迁移与换装；非工业种族不会因为未使用的电力属性显示「缺电暂停」。

验证命令：`npm test`、`npm run build`、`npm run build:pages`、`node scripts/check-pages-build.mjs`。浏览器需覆盖冲突交换 / 取消、单项重置、保留键、刷新持久化、种族与建筑预览、档案筛选 / 技能搜索，以及桌面和 390px 窄屏。
