# 2.3 移动与战斗同步

本轮落实 2.2 评估中的三项 P0，并先精修步兵、采集车、坦克的动作节奏。没有扩展兵种、科技或重做图集。

## 移动与采集

`movement.ts` 使用空间桶查询邻近单位，对每次位移做扫掠圆检测，防止高速穿过其他单位。地面圆形碰撞体同时检查地形和建筑；空中部队独立避让。基础逻辑半径保持 14，32 单格窄路仍可通过。

候选方向结合推进距离和邻居预测位置打分，持续受阻时把附近单位占据的位置加入寻路阻挡。允许闲置友军侧让，已到达编队终点的单位保留位置。编队终点间距为 64，给后续部队留出穿行空间。车辆在空旷处先转向再出发，拥堵时允许边转向边避让，避免转向动作导致运输停滞。

采集点、交付建筑和施工建筑分别分配作业位与外围等待位，单位进入工作范围后才作业。旧存档重叠先分离，嵌入建筑的单位尝试移至附近空地。局部避让不等于全局交通调度；双向极端拥堵、大规模地图的通行效率仍有继续优化空间。

## 发射、命中与阵亡

攻击先进入权威模拟中的 `windups`，动作帧处于准备阶段。前摇完成且目标仍有效、位于射程和视野中，并且射手已瞄准，才生成发射事件。移动、停止和新施工指令打断前摇；前摇时阵亡不会继续开火。

| 武器 | 前摇 | 命中方式 |
| --- | --- | --- |
| 步枪等基础武器 | 0.12 秒（其他默认 0.1 秒） | 发射时即时命中，同时显示短暂射线 |
| 狙击枪 | 0.24 秒 | 即时命中 |
| 坦克炮 | 0.24 秒 | 520 世界单位/秒，落点结算范围伤害 |
| 火炮 | 0.36 秒 | 420 世界单位/秒，落点结算范围伤害 |
| 治疗 | 0.16 秒 | 发射时恢复生命值 |

炮弹记录发射时的伤害、目标落点和范围；射手阵亡后炮弹仍飞行。弹道朝发射时的落点飞行，目标可通过移动躲开爆炸范围。范围伤害排除友军；坦克、火炮的爆炸不伤害空中目标。渲染器根据权威发射时间和持续时间显示飞行、落点、受击和死亡，不再用飞行特效掩盖提前扣血。

## 动作与血条

行走帧按实际位移累计值推进，速度变化时减少脚滑。渲染位置插值与动作使用同一位置来源；停止时短暂收步，核心三类单位只做轻微、以地面接触点为锚的形变和后坐。攻击准备与发射帧由模拟动作阶段驱动，取消攻击后不会残留开火动作。图集仍为每方向两帧待机、四帧移动、两帧攻击/作业、两帧阵亡；本轮改善时序和运动，没有增加美术关键帧或独立炮塔层。

视图公开 `VisibleUnit.maxHp`，从权威玩家科技计算，敌方升级装甲后的生命条比例正确。敌方科技、炮弹伤害/范围及内部来源和目标 ID 不进入公开炮弹视图，视觉事件仍遵守迷雾权限。

## 存档与验证

继续使用 v2 存档：旧存档缺少的新字段采用默认行为，新存档保留前摇和飞行中炮弹，恢复时不额外扩大已探索区域。速度、行进距离、等待位、动作和弹道新增字段均有格式检查。

`npm test`：59 项通过。新增重点验证：

- 20 个步兵通过 32 宽单格窄口，全部抵达各自终点；每步检查与墙面及单位的间距。
- 20 辆采集车共用资源和交付区域，120 秒内每辆至少交付一次、总交付超过 2,000，最小中心距不低于 27.9。
- 攻击准备、发射、命中、伤害、死亡顺序；前摇打断；射手死亡后的独立炮弹；友军不受范围伤害。
- 车辆转向、位移驱动步态、停止收步、敌方升级血条、迷雾载荷过滤，以及前摇和炮弹存档往返。

原有经济、建造、AI 扩张、科技、完整对局、相机和真实 WebSocket 回归继续通过。`npm run build` 通过。自动化场景验证覆盖明确的地图和兵力条件，不代表任意地图的拥堵都已解决。
