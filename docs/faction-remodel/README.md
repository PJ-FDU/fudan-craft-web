## 对应问题与实际实现

| 问题 | 改造 |
| --- | --- |
| 人形单位过于相似 | 七种步兵分别建形：突击兵宽肩重甲、医疗兵白甲与双罐、狙击手兜帽长披风、军官长外套与终端、线列兵布装与卷毯、工兵工具背架、观测员罩衣与传感器。腿部 IK 契约共用，胸肩比例、头部、装备与手持物按角色设计。 |
| 坦克类单位过于相似 | 联邦分为宽体装甲坦克、五对负重轮的长底盘敞开自行炮、竖直相控阵电子战车；远行者分为四轮开放轻车、六轮双联高射炮卡车、通信厢车和收拢式装配运输车。 |
| 生物族粗糙、卡通感强 | 主体从多面球改为连续曲面甲壳，细小甲片和关节降低分段。深色肢节、局部软组织、弯曲角质、贴体血管、薄翼膜形成不同表面。建筑采用根须、叠甲、护肋、嵌入式胚囊和不等高腺管。颜色收敛为橄榄灰、角质褐与暗红组织，呼吸幅度缩小。 |
| 联邦与远行者相似 | 联邦新增设施采用冷灰蓝装甲、刚性集装箱、封闭堡垒与相控阵；远行者采用沙色布料、开放车架、独立篷棚、拉索、支脚与可收拢设备。 |
| 生群獠牙错位 | 弯角按根部、生长方向和长度定位，替代手算中心点。采集车、巢群战士与缚网者的刃爪根部直接连接腕节；背刺、入口獠牙、足爪和加工设施齿列都接到同骨骼的甲壳或筋腱。 |
| 泰坦不够厚重 | 取消以碰撞半径逐轴压缩泰坦，恢复等比显示；加宽胸肩、髋部、腿甲、站距和足部，缩小并内收头部，增加肩部武器舱、左臂护盾和带加固导杆的重炮。 |
| 星能整体过于简单 | 八类单位分别采用采集双臂、双晶枪、透镜炮、四足巨构、分层翼面、双面分段护盾、纵向星盘和四叶相位阵列。九类建筑分别建形，补充承力塔、入口、装配夹具、双晶反应器、加工轨道与闸门分段护甲。白瓷外壳、凹入合金框架、金色导体和小面积青色发光保持统一材质语言。 |

继续使用既有 16 类材质及其法线图，本轮未新增材质图片。模型依然采用程序化 RTS 的风格化轮廓，新增细节来自实体几何与已有材质。

## 源码锚点

- [humanoid-models.ts](../../src/game/humanoid-models.ts)：七种人形角色、服装和手持设备。
- [tracked-models.ts](../../src/game/tracked-models.ts)：三种联邦履带底盘。
- [organic-models.ts](../../src/game/organic-models.ts)：生物单位、建筑、血管和肢节。
- [expedition-models.ts](../../src/game/expedition-models.ts)：远行者车辆、营地及装配站两种形态。
- [mobile-models.ts](../../src/game/mobile-models.ts)：`titan` 的胸肩、头部、承重腿和武器。
- [models-3d.ts](../../src/game/models-3d.ts)：战场与图鉴统一实例化、泰坦等比显示。
- [stellar-unit-models.ts](../../src/game/stellar-unit-models.ts)：星能八类单位与骨骼动作。
- [stellar-building-models.ts](../../src/game/stellar-building-models.ts)：星能九类建筑、承力塔与生产动作。
- [stellar-model-parts.ts](../../src/game/stellar-model-parts.ts)：分段能量环、晶核夹架和透镜聚焦器。
- [faction-building-models.ts](../../src/game/faction-building-models.ts)：联邦新增设施及建筑分派。
- [faction-unit-models.ts](../../src/game/faction-unit-models.ts)：单位种族分派。
- [model-parts.ts](../../src/game/model-parts.ts)：平滑背甲、小甲片、关节球、弯角、肢节和薄膜的共享原型。
- [faction-model-parts.ts](../../src/game/faction-model-parts.ts)：物理材质参数、两端点肢节和根部锚定的 `horn`。
- [unit-rig.ts](../../src/game/unit-rig.ts)：轮组布局及动画；`mobile-models.ts` 分派共用人形和履带模型。

`[SSOT]` 模型外观以以上构建函数为准，最新实拍是当前版本的检查证据；历史图片不能作为当前验收依据。

`[RIG]` 非机甲步兵保留 `8.5 / 8 / 1.65`，泰坦保留 `11.5 / 10.5 / 2.6` 腿段契约。履带炮管保留静止 `z=3` 的后坐基准；自行炮五对轮，坦克与电子战车四对轮。新增构件绑定既有骨骼系统。

`[ATTACHMENT]` 弯角原型底面中心为局部 `(0,-.5,0)`。调用 `horn` 时传入根部，不能传入角的中心。角根必须嵌入同骨骼的支撑几何；仅在静态下贴近另一骨骼不算有效连接。

`[SCALE]` 泰坦实例的三轴显示比例统一为 `94 / 68`；肩甲与武器可以伸出寻路圆。碰撞半径、战斗数值和移动速度继续由 `STATS` 独立定义。

`[BATCH]` 通过 `Parts` 的 solid/team/lamp 合批，定制模型最多三个材质网格，部分生物建筑仅两个。关节与血管没有各自创建 Mesh。

## 最新验证记录（2026-11-21）

- `npm run build`：通过 TypeScript、Vite 和服务端构建。Vite 仍提示主包超过 500 kB。
- `npm test`：167 / 167 通过。
- 角根检查：生群全部 18 类单位和建筑共 211 根角刺，逐一计算角根到同骨骼非角刺几何的距离，并检查是否位于封闭几何内部；最大间距小于 `0.000001` 个模型单位。
- 动作检查：泰坦、生群和星能共 36 个模型，覆盖静止、移动、攻击、后坐、采集、施法、生产和倒地共 576 个姿态，检查 18,191,232 个变形后顶点及所有骨骼矩阵，无非有限坐标或异常膨胀。
- 泰坦检查：三轴缩放一致；八个行走相位的着地踝关节符合既有腿段与足高契约。
- 实际图鉴：检查星能八类单位和九类建筑，并检查泰坦移动/攻击、生群前爪/基地呼吸、星能巨构攻击/护盾施法/圣所生产。
- 几何开销：36 个改动模型的所有材质合计 1,136,952 顶点，每个模型最多三个材质网格。该数字是几何统计，非帧率基准。
