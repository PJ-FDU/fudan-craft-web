# 中英文显示与语音

语言状态与持久化的事实来源是 `src/game/locale.ts`，英文文案位于 `src/game/locale-dictionary.ts`；语音内容与文件路径以 `src/game/audio-catalog.ts` 为准。主菜单右上角可直接切换；首页设置和战局菜单中的「语言与语音」提供相同选项。默认中文，浏览器键 `fudancraft-language-v1` 保存 `zh` / `en`。

- **[I18N-PRESENTATION]** `localizeDocument` 只翻译 DOM 文本、提示、无障碍标签与占位符；缓存原文以支持中英往返切换。Engine 的单位数据、地图 ID、资源、存档、网络命令不随显示语言改变。
- **[I18N-CANVAS]** 战场和动画图鉴的 Canvas 文字必须经过 `t()`；不能仅依赖 DOM 翻译。
- **[I18N-IDENTITY]** 玩家输入与房间中的姓名保持原样。玩家姓名、原生语言名称、已由语音模块选择语言的字幕使用 `data-i18n-ignore`。
- **[I18N-COVERAGE]** 新增界面文案必须补充英文词条。英文界面中除语言切换名称和玩家内容外，不应出现中文残片；动态文案需同时检查名称、数值、前置条件和错误状态。长说明优先提供完整句译文，短动态标签使用共享词条。
- **[I18N-AUDIO]** 切换语言取消当前与加载中的旧录音，下一次触发播放目标语言的实际 MP3；不能只切换字幕。

浏览器已验证首页与刷新持久化、战役设置和八张地图、档案与科技路线、操作指南、多人房间入口、战场动态状态、建筑和资源详情、战局菜单与动画图鉴。390 × 844 的英文首页与地图列表无横向溢出，手机语言按钮保持可见。两种渲染模式都经过真实点击验证；构建与 116 项现有回归测试通过。
