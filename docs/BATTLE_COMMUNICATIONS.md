# 战场文字与队友语音

联机对局右上方「聊天」打开通讯面板。桌面按 Enter 打开，Shift+Enter 打开队友频道，Esc 收起。聊天不会暂停对局；输入框、输入法组合输入和频道下拉不会触发战场快捷键。

- 公屏：只发给当前房间中在线的人类玩家。
- 仅队友：按照权威对局的 `Player.team` 分发；合作对抗 AI 的人类玩家同队，自由对战各自成队。AI 不接收文字或语音。自由对战的队友频道只有自己。
- 每条最多 300 字，每位玩家 5 秒内最多发送 5 条。发送者姓名、阵营和队伍来自连接绑定席位，忽略客户端伪造字段。
- 客户端保留最近 100 条消息，收起时显示未读数量和最多三条最近消息，预览八秒后消失。重连保留本页记录，新房间清空。消息不写入战役存档，重连期间不缓存待发送消息。姓名与正文使用 `textContent`，禁止解析 HTML 或自动翻译玩家输入。
- 「快捷消息」无需打开输入框，提供资源不足、准备进攻、防守基地、准备好了、请等待、谢谢六种预设；可切换队友 / 公屏，与文字消息共用频率限制。预设由权威服务校验并按接收者语言显示。
- 「队友语音与玩家」可屏蔽 / 取消屏蔽某人的文字、快捷消息和标记。屏蔽仅影响本页显示，不影响其他玩家；换房清空。语音静音是独立控制。

联机小地图长按 450ms 或右键打开「进攻、危险、集合、支援」标记菜单。移动超过 8px 取消长按并继续拖动镜头；轻点仍定位镜头。标记只发给在线队友，在小地图和战场显示八秒，并产生队友频道通知。服务校验当前对局地图边界、身份和种类，每人两秒最多一个；大厅不接受标记。客户端显示冷却提示，不缓存离线操作。

地图标记的协议类型为 `map-ping`；P2P 原有 `ping` 仅用于保活，两者不能混用。

语音默认关闭。在「队友语音与玩家」中主动开启后请求麦克风权限。支持自由说话 / 按住说话两种模式，按住按钮或 V 传音，松手、触摸取消、失焦、页面隐藏时停止传音；输入文字时 V 不触发。手动麦克风静音优先于按住说话。切换模式释放已有按压状态，权限请求期间松手也不会留下开启的麦克风。

每位已加入语音的队友可独立静音和调整 0–100% 音量，通过 `GainNode` 控制本地接收，避免部分手机忽略音频元素音量；不会退出对局或关闭其他队友的声音。实际音频波形 RMS 驱动「正在说话」提示，AudioContext 不可用时回退音频元素播放。停止时释放增益和分析节点、定时采样及 AudioContext。浏览器阻止自动播放时提供「播放队友语音」。仅有在线队友时可开启。

媒体使用独立 WebRTC 音频连接，不经过战局状态压缩或模拟 Worker，不记录音频。服务端 / 房主 Worker 只转发同队且双方已开启的当前语音会话信令。双方 session 必须匹配；断线、席位重连或队伍变更使旧信令失效。取消权限请求后晚到的流立即停止；离开房间、连接关闭或 pagehide 停止采集、关闭连接并移除音频节点。

手机的左下小地图独占选中信息与快捷指令两行，地图保持正方形，指令放到右侧四列，点击区域至少 44px。聊天面板受 `visualViewport` 和安全区约束，正文可触摸滚动，频道使用 `GameSelect`。

## 网络要求

麦克风需要 HTTPS（localhost 可用于验证）及浏览器授权。拒绝权限、无设备、协商失败和连接中断会显示提示，可以关闭后重试。

- Pages P2P：`P2PConnection.voiceIceServers()` 复用 Metered 给现有连接签发的临时 ICE / TURN 配置。
- 服务器版：默认使用 STUN 尝试直连。受限 NAT / 防火墙下需要 TURN，可在构建前通过 `VITE_VOICE_ICE_SERVERS` 提供 JSON 格式的 `RTCIceServer[]`。此变量会进入客户端，配置应使用适合公开客户端的短期凭据，不能放服务端管理密钥。修改后重新构建。
- ICE 失败时尝试有限次数重新协商；仍失败则提示关闭后重试。外部网络及实体手机的权限 / 后台播放行为需在部署环境验证。

## 源码与验证

- `src/network/room-comms.ts`：消息验证、身份绑定、队伍隔离、发送频率和语音 session。
- `server/index.ts`、`src/network/host-room.ts`：两种权威房间接入；媒体状态不持久化。
- `src/game/battle-chat.ts`、`src/game/team-voice.ts`：文字界面、输入屏蔽、麦克风生命周期及 WebRTC。
- `src/mobile-ui.css`、`src/battle-chat.css`：小地图与通讯布局。
- `tests/comms.test.ts`：身份伪造、频道隔离、聊天 / 快捷消息共用限流、地图边界与标记冷却、过期会话、断线 / 队伍变更与 Pages 席位恢复。
- `tests/team-voice.test.ts`：按住说话、权限异步返回、手动静音优先级与取消后停止媒体。
- `tests/comms-transport.test.ts`：P2P 心跳与地图标记分流、房主身份绑定和控制 / 快照通道边界。

验证使用完整测试、双构建与 Pages 发布检查；浏览器覆盖双客户端文字收发、模拟麦克风的实际 WebRTC 连接 / 静音 / 停止、离房清理，以及手机横竖屏和短视口输入。模拟麦克风通过不等于实体手机和公网 TURN 实测。

浏览器验收覆盖服务器版和 Pages P2P 双客户端收发、真实触摸长按标记、快捷消息预览及到期、屏蔽 / 取消屏蔽、双方 `inbound-rtp` 音频数据包、按住说话 / 取消 / 失焦、队友静音与音量、音频驱动的说话提示和离房清理。窄屏覆盖 320×568、390×660、844×390、390×300；实体手机、耳机和公网 TURN 尚待部署环境实测。
